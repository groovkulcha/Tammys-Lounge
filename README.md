# Tammy's Lounge

An original responsive one-page marketing mock site for a fictional restaurant-and-nightlife concept. It is designed as a presentation asset for early marketing and brand-development conversations.

## Included

- Original midnight navy, ultraviolet, hot coral, electric cyan, and yellow visual direction
- Responsive navigation, hero, concept messaging, sample menu, event listings, and contact/location placeholders
- No copied Capital Bar & Grille logos, photos, menu copy, or proprietary website assets
- Plain HTML, CSS, and JavaScript; no build process required

## Preview locally

Open `index.html` in a modern browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then save.
5. GitHub will display the live Pages URL after deployment.

## Replace before a live campaign

Replace the placeholder address, hours, email, reservation flow, menu, prices, event information, and imagery with verified business-approved content.
